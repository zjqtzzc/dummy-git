# Seti 图标快照

由 `scripts/generate-seti.mjs` 从 VS Code 自带的 `theme-seti` 扩展生成，不要手改。
VS Code 更新了 Seti 就重跑一次。

- `seti.woff`：Seti 图标字体。
- `setiMap.json`：图标 id → 字形与颜色；深色、浅色各一套「文件名 / 扩展名 → 图标 id」。
