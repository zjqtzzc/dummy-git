# 更新日志

## 0.1.2

- Stash 模式里，stash 下的文件右键 Apply Selected Files：只取回选中的文件，stash 保留。
- 已有 stash 可以改名（右键 Rename…）。
- Rollback 改成编辑器标签页：树上勾选要撤的文件，底栏显示勾了几个。
- 右键 Stash 改成编辑器标签页：可改勾选，可写名字。
- Log 右栏和对话框里的文件树重新按目录分组（之前错成了平铺）。
- 文件名里的 `[`、`*`、`?` 不再被当成通配符：提交、Rollback、Stash 不会顺带动到旁边的文件。
- 冲突标记只认行首的 `<<<<<<<` / `>>>>>>>`，Markdown 里的 `=======` 分隔线不再误判。
- 提交图和标签不再按 main / master 猜主干，只置顶当前检出的分支。
- Windows 上盘符大小写对不上时，外部 git 的改动也能刷新面板。

## 0.1.1

- Commit 面板右键 Open File：在编辑器里打开磁盘上的文件。
- 改名后又删掉新路径的文件，提交、Rollback、Stash 不再留下一半。
- Update 进行中切换、删除或改名分支，不再更新到别的分支，也不会把删掉的分支建回来。
- Commit 面板：外部提交后不再残留多余的目录行；同一文件同时是删除和未跟踪时，右键和打开 diff 各认各的。
- Log 面板收起再展开后，右栏不再变成 0 宽。
- 冲突组的继续 / 放弃按钮跟随主题颜色。

首个公开版本。Log、Commit、同步、分支、stash、提交图、冲突处理、改写历史。
