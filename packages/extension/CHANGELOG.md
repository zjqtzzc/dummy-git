# 更新日志

## 0.1.1

- Commit 面板右键 Open File：在编辑器里打开磁盘上的文件。
- 改名后又删掉新路径的文件，提交、Rollback、Stash 不再留下一半。
- Update 进行中切换、删除或改名分支，不再更新到别的分支，也不会把删掉的分支建回来。
- Commit 面板：外部提交后不再残留多余的目录行；同一文件同时是删除和未跟踪时，右键和打开 diff 各认各的。
- Log 面板收起再展开后，右栏不再变成 0 宽。
- 冲突组的继续 / 放弃按钮跟随主题颜色。
