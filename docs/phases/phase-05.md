## 一、交互细节（逐条定）

**已定**
1. **过滤栏**：提交列表正上方一行，只占中间那栏（同 IDEA）。左边搜索框占满剩余宽度，右边 `Branch`、`User`、`Date`、`Paths` 四个按钮。
   未生效时按钮只写名字；生效后写当前值（`User: Me`），后面带 × 清除。中间栏窄时搜索框先缩，按钮文字不截断。

2. **选值用原生 QuickPick**（扩展弹，可搜索、键盘与主题都是原生的），把选中的值还给页面；过滤状态在页面。
   这是过渡：以后一定换成按钮正下方的下拉菜单（需求池），只换弹框这一层。
3. **分支**：单选。Branch 按钮弹 QuickPick 列本地与远程分支；左栏**双击**分支（含 HEAD 行 = 当前分支）同效。
   正在过滤的分支被删掉，过滤自动清除（`tech/traps.md`）。走骨架：换起点重取一万条。
4. **作者**：单选。第一项 **Me**（git 配置的 `user.name` 与 `user.email`），下面是这一万条里出现过的作者，按提交数从多到少。
   匹配用「名字 <邮箱>」整串、按普通文字（`--author` + `-F`），不用正则。
5. **日期**：`Last 24 Hours`、`Last 7 Days`、`Last Month` 三个预设，不做自定义。在页面里按骨架的时间筛，不问 git。
6. **路径**：Paths 按钮弹 QuickPick，列出所有被跟踪的文件与由它们推出的目录，可搜索；单选；`git log -- <路径>`，不跟改名（不加 `--follow`）。
7. **搜索框：说明文字或 hash**（同 IDEA 的「Text or hash」）。两路结果取并集：
   - 说明文字：普通文字、不分大小写（`--grep` + `-F -i`）；
   - hash：输入是 4 个以上十六进制字符时，也匹配以它开头的 hash（在页面里对骨架做）。4 是 git 缩写的最短长度，免得 `add`、`fix` 这类短词误中。
   停止输入 300 毫秒后才查；查询中旧列表留着，过滤栏右侧转圈（`tech/performance.md` 第 3 节）。
8. **跳到 hash / ref：这一阶段不做**（移入需求池）。
9. **组合**：几个过滤取交集（同 IDEA）。过滤后原来选中的提交还在就保持选中，不在就清空选中。
   分支过滤例外：它重取骨架，选中照骨架刷新的规则（还在就保持，不在就改选 HEAD 那条）。
   没有结果时正中灰字 `No commits match the filters`。仓库变化时自动重查。过滤条件存进 `viewState`。
10. **复制**：提交列表上 Ctrl+C（Mac 上 Cmd+C）复制选中提交的完整说明，下面两行 `Author: 名字 <邮箱>`、`Date: 2026/9/20 09:05`。
    提交行右键菜单 **Copy Hash**（完整 hash），提交列表的第一个原生右键菜单。
    分支树上 Ctrl+C 复制选中分支的名字（本地分支是全名，远程分支是 `origin/feat`，HEAD 行是当前分支名，detached 时是完整 hash；目录、分组不复制）。

## 二、实现顺序

每步一个概念，`pnpm check` 通过、手动看过、用户确认后单独提交。

1. **过滤栏 + 日期过滤**：提交列表上方一行（搜索框先占位、四个按钮）；通用的原生选择协议命令 `pick`（标题 + 选项，返回选中的序号）；
   页面持有过滤条件、存 `viewState`，× 清除；按骨架时间筛出可见的 hash；选中保持或清空；空结果文字。
2. **搜索框**：扩展侧「在给定的 hash 里按条件筛」的读命令（`log --no-walk --stdin` + `--grep -F -i`），页面把骨架的 hash 一起发过去；
   与页面里的 hash 前缀匹配取并集；300 毫秒防抖、查询中转圈、只收最新一次的结果。实测一万条以上仓库的耗时，写进 `tech/performance.md`。
3. **作者**：`pickAuthor`（Me + 这一万条里的作者按提交数排），同一条筛选命令加 `--author -F`。
4. **路径**：`pickPath`（被跟踪的文件 + 推出的目录），筛选命令加 `-- <路径>`。
5. **分支**：骨架命令可带起点；Branch 按钮（QuickPick 列分支）与左栏双击；分支被删时过滤落空。
6. **复制**：提交列表 Ctrl+C；提交行右键 Copy Hash；分支树 Ctrl+C 复制分支名。
7. **验收**：「要核对的条目」逐条勾过；验收句手动走一遍；`pnpm check`；本文状态改为完成。
